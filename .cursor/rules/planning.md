# mac-llm planning workflow

Planning is manual and high-control.

When asked to plan:

- use GrillMe if available to challenge assumptions
- use `to-prd` for non-trivial milestone behavior
- use `to-issues` to produce small implementation issues
- create issues only for the current milestone unless told otherwise
- use `agent:draft` by default
- use `agent:ready` only when implementation should launch
- add exactly one worker label: `worker:claude` or `worker:cursor`
- do not implement during planning
